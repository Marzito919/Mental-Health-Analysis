# Mental Illness Statistics Analysis

This project presents a comprehensive statistical analysis of global mental illness prevalence using Python. The dataset includes data on schizophrenia, depression, anxiety, bipolar disorder, and eating disorders, covering multiple countries and decades (1990 onward).

## Dataset

- *Source*: Prevalence of mental illnesses worldwide
- *Rows*: 6420
- *Columns*: 8 (Country, Code, Year, and five mental illness types)
- *Data Type*: Time-series and cross-country

## Tools Used

- *Python (Pandas, Matplotlib, Seaborn)*
- *Jupyter Notebook (.ipynb)*
- *Kaggle* (initial development)
- *GitHub* (version control)

## Key Analysis Performed

Data cleaning and null value handling
Outlier detection using boxplots
Frequency distribution using histograms
Correlation heatmap analysis
Scatter plot (Depression vs Anxiety)
Pie chart of top countries with schizophrenia
Bar chart of countries with highest depression rates
Multivariate and comparative insights


## Insights

Depression is the most common disorder globally (avg > 4%)
Guam and Northern Mariana Islands have high schizophrenia rates
Depression and anxiety show positive correlation
Bipolar and eating disorders are closely linked
Countries affected by conflict tend to show higher mental illness rates
